# Documentation images

The public source export includes these native SyFrack images:

- `studio-en.png`, `studio-fr.png`: Simple 3D workspace in English and French,
  captured on 22 October 2026. The saved native 3D render reference is explicitly
  labelled in the viewport.
- `studio-2d-en.png`: Simple 2D colour controls over the unified creation graph,
  captured on 22 October 2026.
- `studio-render-en.png`, `studio-render-fr.png`: redesigned native render/export
  window, captured on 22 October 2026, with format, quality, destination and the
  exact output filenames.
- `studio-20-atelier-nodal.png`, `studio-20-atelier-nodal-compact.png`: the
  20 October nodal editor revision at full size and 1000 × 640, illustrating
  typed sockets, the path library and connection inspector. These captures
  precede the Simple/Advanced selector.
- `breath-of-the-titans.jpg`: web illustration of the native 2D showcase.
- `breath-of-the-titans.png`, `palais-rose-sur-mer.png`: completed native render
  references used by the `studio_capture` example; these are also editable via
  the corresponding showcase/environment scene files.

Older workbench screenshots, render masters, raw EXR files and checkpoints
remain in the original development workspace and are not part of this source
export. The public images do not require those local files.
