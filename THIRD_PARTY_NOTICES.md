# Third-party notices

## Rust dependencies

Rust dependencies are resolved by Cargo and recorded in `Cargo.lock`. Their
source and licenses remain with their respective packages. This source export
does not vendor Cargo's registry or redistribute prebuilt dependency binaries.
The Windows release packager preserves dependency license/notice files and
font attribution in `licenses/`, together with `licenses/DEPENDENCIES.json`.
This inventory covers Cargo's resolved Windows dependency set, including some
build/test packages, rather than claiming that every entry is linked into
both executables. Where a crate omits its own license copy and offers Apache
2.0, the shared Apache text is supplied and that choice is recorded. Other
missing texts are pinned in `assets/licenses/` with source URLs and SHA-256.
The embedded egui fonts retain their own font license texts and credits.

Release binaries link the C runtime statically; a Microsoft redistributable is
not copied into the archive. The project does not apply a code signature to
these experimental executables.

## Optional Open Image Denoise

Open Image Denoise is a separate RenderKit project. Its runtime is not bundled
in this source export. The optional installer downloads the pinned official
Windows package and preserves its bundled license and third-party notices.
See the [official project](https://github.com/RenderKit/oidn).

## SyFrack assets

The synthetic `neon-night.exr` scene environment and `studio.exr` profiling
environment are native project assets generated by the `cyberpunk_scene` and
`hdri_lab` examples, respectively; the CC0 table above concerns the two external
panoramas only.

The graph thumbnails, native fractal showcase images and small symbol font
shipped here are project assets. The symbol font is generated by
`crates/syfrack-app/assets/make_symbols.py`; fontTools is needed only to rebuild
that asset, not to compile or run Studio.
